# OPC-2 v05：问题图解 + PPT 讲解 + 真实片段

目标：90 秒竖屏静音审阅稿。用户反馈前置准备不足，故在实际生产演示前加个人动机、核心疑问与四项准备图解；后半段按“讲解页 → 真实证据片段”交替推进。

## 画面原则

- 前置插画与章节页由本地绘图代码生成，标“流程示意”；它们解释思路，不冒充当时录屏、真实抖音/小红书页面或已做过的市场调研。零新增付费生成/API调用。
- 工作台截图来自 v03 已完成的 Explorer 与固定只读回看，标“今日只读回看”。不触发网页生成、保存或配置页。
- 实际失败画面、S007 对照与最终检查版仅使用 v03 已核 SHA 的源素材。费用及验收以 OPC-1 `Validation-Report-v2.txt` 为准。
- 结构：动机 5s → 问题 6s → 四项准备 10s → 剧本画面 6s → 工具分工 8s → 工作台 6s → 人物问题/实证 4+6s → 分镜问题/实证 4+6s → 动作问题/实证 4+6s → 结果 9s → 费用 5s → 下一步 5s，共 90 秒。
