依据用户2026-10-08两项反馈。180秒、竖屏720×1280、24fps静音审阅版。

- 全片字幕换为苹方SC Semibold，31–36px，短句居中，细描边；去掉黑色卡片、底部进度条与句尾标点。

- 158–180秒归纳制作流程、注意项、费用成本。没有逐镜报价、试验预算表、登录提示或观众/声音评估清单。
