# OPC-2 v06：讲解、案例图与逐句字幕

依据用户新提供的复盘稿和9张图片，将内容整理为9章、19个画面段、180秒静音审阅稿。问题章节持续20–22秒，章节内切换案例图；费用章节34秒，包含搭建测试、早期角色冲突和重制返工。精确时长为编辑假设，旧90秒版保留。

- `voiceover.md`：完整口播文稿；`subtitles.srt` / `.ass`：逐句字幕，已烧入MP4。

- `plan.md`：本次范围、预算、探索和制作约束。
- `prepare.py`：从章节定义更新统一事实源，导出配套文稿和字幕。
- `render.py`：本地排版与视频合成，不调用生成模型。

复现顺序：从HiFox附件`01a0f172-4617-7eb4-94bf-6708bbaaf4f9`取回图片放到`assets/`，确认本机原视频仍位于事实源记录的路径。运行 `python3 prepare.py`，再 `python3 render.py`。素材哈希变更会阻止渲染。图片和成片只在本地及交付包中，不提交媒体到Git。
