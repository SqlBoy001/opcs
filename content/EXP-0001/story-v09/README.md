# v09 个人OPC经历叙事版

定位：一个人尝试AI漫剧制作的真实实验复盘。观众能看到做出了什么、为什么返工、投入了多少，不包装成收益教程或稳定量产承诺。

成片185秒，720×1280、24fps，静音字幕审阅版。标题：一个人做60秒AI漫剧，为什么总在返工？

| 段落 | 修改 |
|---|---|
| 0–3秒 | 真实近现代军服错图，圈注帽檐、立领与双排扣 |
| 3–6秒 | 巨型脚镣失败候选，圈出比例异常 |
| 6–10秒 | 两个真实成片镜头快切，建立这次60秒产物的预期 |
| 10–15秒 | 工作台与场景画面，承诺讲清流程、踩坑、花费 |
| 15–135秒 | 接“先说开工前”，保留准备、搭建及四处问题的中段内容 |
| 135–162秒 | 先看成片，再讲前期200元套餐充值、本次视频约75元；DeepSeek/MiniMax未计，优化需继续投入 |
| 162–185秒 | 结合工作台、服装前后与取刀剪辑回看经验，结尾落在“把错误拦在下一步之前” |

全片保留v08苹方SC Semibold字幕、短句居中、无黑底卡片。撤掉原“不报班”开场、三张目录式总结卡；收尾采用“结果→代价→收获”，费用浮字叠在真实画面上。

统一源为上级content.json的story_v09；prepare.py生成文稿/SRT，render.py本地合成，check.py及review_frames.py为内容定向自检。旧版本保留，原媒体只读，新增付费生成/API调用0，没有配音/新录屏/发布/业务修改。

费用沿用用户2026-10-08确认及既有v2账单；200元是充值，不推断已全数消耗，75元为本次火山视频现金粗估，不是全工具总成本或固定每集价。新版本没有宣称完成实时账单审计。
